# Single-Cycle RV32I Processor (Intel Quartus Project)

This repository contains the Intel Quartus project for a single-cycle processor implementing the RISC-V 32-bit (RV32I) base integer instruction set. This project was developed for the **MazeSolver Bot (MB)** theme.

**Team ID:** 2401
**Project:** `t1c_riscv_cpu`

## Description

This is a simple single-cycle implementation of a 32-bit RISC-V processor, packaged as an Intel Quartus project. It follows a classic Harvard architecture, utilizing separate memories for instructions and data. The control unit generates all control signals combinatorially based on the instruction's opcode.

## Project Structure

The repository is organized as a complete Intel Quartus project.

* `t1c_riscv_cpu/`: The root directory for the Quartus project.
* `code/`: Contains all Verilog source files (`.v`), RISC-V assembly tests (`.s`), and compiled hex files (`.hex`).
* `code/components/`: Contains all sub-modules (ALU, decoders, MUXs, etc.).
* `simulation/modelsim/`: Contains ModelSim simulation scripts (`.do`), waveform files (`.wlf`), and transcripts.
* `output_files/`: Contains the compilation reports (`.rpt`), synthesis summaries (`.summary`), and log files generated by Quartus.
* `db/` & `incremental_db/`: Quartus project databases. These are auto-generated.
* `t1c_riscv_cpu.qpf`: The Quartus Project File.
* `t1c_riscv_cpu.qsf`: The Quartus Settings File (pin assignments, device selection, etc.).

## Features

* **RV32I Base Integer Instruction Set:** Implements a core set of RV32I instructions, including:
    * **R-type:** `add`, `sub`, `sll`, `slt`, `sltu`, `xor`, `srl`, `sra`, `or`, `and`
    * **I-type:** `addi`, `slti`, `sltiu`, `xori`, `ori`, `andi`, `slli`, `srli`, `srai`, `lb`, `lh`, `lw`, `lbu`, `lhu`, `jalr`
    * **S-type:** `sb`, `sh`, `sw`
    * **B-type:** `beq`, `bne`, `blt`, `bge`, `bltu`, `bgeu`
    * **U-type:** `lui`, `auipc`
    * **J-type:** `jal`
* **Single-Cycle Datapath:** All instructions execute in a single clock cycle.
* **Harvard Architecture:** Uses separate `instr_mem` and `data_mem` modules.

## Simulation

The project is set up for simulation using **ModelSim**, which can be run from within Quartus (Nativelink) or standalone.

1.  **Test Program:** The assembly program is in `code/rv32i_test.s`. This is assembled into `code/rv32i_test.hex`.
2.  **Memory Initialization:** The `instr_mem.v` module is configured to load `rv32i_test.hex` at the start of simulation.
3.  **Running in ModelSim:**
    * Open the `t1c_riscv_cpu.qpf` project in Quartus.
    * Go to `Tools > Run Simulation Tool > RTL Simulation`.
    * Alternatively, you can manually run the `.do` script (`simulation/modelsim/t1c_riscv_cpu_run_msim_rtl_verilog.do`) in ModelSim.
